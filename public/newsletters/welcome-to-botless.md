We are thrilled to officially launch **Botless**, a centralized directory of developer tools, lookup utilities, and resources built specifically for Discord server admins and community builders.

## What is Botless?

Botless provides instant, client-side tools that don't require inviting heavy bots or configuring complex oauth setups.

### Featured Utilities

* **Vanity URL Checker:** Instant verification of custom invite availability with automatic input sanitization.
* **Webhook Builder:** Live preview and message dispatching directly through Discord webhooks.
* **Automod Library:** Copy-paste regex rules and safety filters tailored for native Discord moderation.
