We're proud to release the first version of **Discapp Docs**! This is the start to a place where you can learn not just about Discapp but also Discord, APIs, and more!

Check it out here: **https://docs.discapp.org**

### Our Plans

Over the next versions, we hope to release updates that improve the UI and UX of the docs! This includes better navigation, colors, options, and more. Once we have that, the plan is to work on making guides for Discord, development, and more so than you can simply search up what you're looking for or ask a question and immediately get an answer!

### Can We Contribute?

Yes! You can help make guides better or make your own guides by either requesting them on our community discord server or by making a pull request on the discapp-docs github page!
